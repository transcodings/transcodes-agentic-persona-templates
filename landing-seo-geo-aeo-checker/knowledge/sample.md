# How to use this Knowledge Base

This document tells you where the blank report is. It does not contain the template.

The blank report is one Skill. Open that Skill and use only the files in its `references/` folder.

| Skill | What it is | What to copy |
| --- | --- | --- |
| `seo-report-template` | Blank SEO, GEO, and AEO report | `references/report-template.md`, `references/report-template.pdf` |

Copy those files for the customer. Do not edit the files in the Skill. After the audit script prints the scores, save the finished PDF in this Knowledge Base with the description and keywords from the Markdown template.
