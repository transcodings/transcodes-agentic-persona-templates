---
description: Every customer audit covers Tier 1, Tier 2, Tier 3, answer-engine readiness, and generative-engine readiness.
---
# Must
- Run all five layers on every landing audit: Tier 1 technical eligibility, Tier 2 relevance and experience, Tier 3 authority and competitive depth, AEO readiness, and GEO readiness.
- Separate site-wide checks from target-page checks and state which URLs you sampled.
- Put blocking Tier 1 failures at the top of the fix list, before copy or schema polish.
- Keep AEO and GEO in the same report as SEO. Answer engines and generative engines both depend on crawl, index, and visible quality.
- For every Fail, name what to change and how to change it. A layer score without that pair is not a finished audit.

# Never
- Never deliver a title-and-description review and call it the audit.
- Never skip GEO or AEO because the page is “only a landing page.”
- Never treat GEO as a duplicate of AEO. AEO checks search-answer eligibility. GEO checks whether a generative engine can quote this brand accurately.
- Never promise ranking or citation from passing a checklist.
