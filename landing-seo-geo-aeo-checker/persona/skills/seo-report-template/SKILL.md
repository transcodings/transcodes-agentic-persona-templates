# seo-report-template

Open this skill when the audit needs the blank report. The audit skill calculates the scores. This skill only holds the template.

1. Read `references/report-template.md` for the description line and the keywords.
2. Copy `references/report-template.pdf`. Fill the copy for this customer. Do not replace the file in this skill.
3. Save the finished PDF, and the same description and keywords, into the linked Knowledge Base. A layer the script did not score is `0`.
