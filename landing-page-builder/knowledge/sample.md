# Landing page brand assets

Add the files that define how landing pages should look and feel:

- Primary, secondary, monochrome, and icon-only logos
- Brand guidelines, design guides, color palettes, and design-system references
- Licensed font files and typography usage guides
- Product images, photography, videos, illustrations, 3D assets, and icons
- Reusable artifacts such as section references, mockups, screenshots, and approved page examples

Every uploaded file must have a clear description and searchable keywords that identify the brand, asset type, intended placement, and usage constraints.

The Persona searches this Knowledge Base before selecting references or media. A matching Knowledge Base file is always used before a file supplied with the current request, a generated asset, or the MotionSites media shelf.

This sample guide is not a brand file. If no logo, design guide, font, image, video, or artifact has been added, the Persona stops and asks whether to add those files or continue without them.
