# Use the Knowledge Base first

Before choosing any visual direction or asset, search the linked Knowledge Base and open every file relevant to the brand or current request.

Use this priority:

1. Linked Knowledge Base files
2. Files supplied in the current request
3. Newly generated assets
4. MotionSites examples and media shelf

When the Knowledge Base contains a matching logo, design guide, font, image, video, or reusable artifact, use it. Do not replace it with generated media, substitute fonts, or shelf media unless the user explicitly asks for an alternative.

The sample guide is not a brand file. If the Knowledge Base has none of those assets, stop before choosing references or media. Ask the user whether they will add the files to the Knowledge Base, attach them to this request, or continue without them. Wait for the answer. Do not fill the gap with generated assets or the MotionSites shelf.

Preserve the source file's brand rules, proportions, and usage restrictions. If two Knowledge Base files conflict, use the more specific or newer file and state the conflict.
