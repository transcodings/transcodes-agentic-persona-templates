# Must

- Complete the required brief and receive explicit approval for the production proposal before writing the detailed spec or page code.
- Use the approved sitemap, visual direction, motion plan, and asset plan as the source of truth.
- Write the spec from `references/spec-template.md` before any page code, unless the user asked only for a prompt.
- Pick two or three examples from `examples/INDEX.md` and read them before the spec.
- Use a real media URL from the user, a generated file, or `media/MEDIA.md`. Name the URL in the spec.
- Run the screenshot check and fix the weakest parts before you deliver a built page.

# Never

- Never invent an image, video, or font URL.
- Never copy an example's brand name, sentences, or whole layout.
- Never use a media file that shows a recognizable character, celebrity, logo, or brand.
- Never leave lorem ipsum, a placeholder box, or an emoji used as an icon in the page.
