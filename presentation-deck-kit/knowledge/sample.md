# How to use this Knowledge Base

This document tells you where the templates are. It does not contain a page layout.

Each visual system is one Skill. Open that Skill and use only the files in its `references/` folder.

| Skill | Look | What to copy |
| --- | --- | --- |
| `ppt-style-swiss` | Swiss Grid | `references/starter.html` and `references/catalog.html` |
| `ppt-style-night` | Night Console | `references/starter.html` and `references/catalog.html` |
| `ppt-style-atelier` | Paper Atelier | `references/starter.html` and `references/catalog.html` |
| `ppt-style-neutral` | Original neutral kit | `references/starter.html` and `references/catalog.html` |

Also read `references/deck-kit.md` and `references/design.md` inside the Skill you chose. Use one Skill for the whole deck. Do not mix Skills. Print from the `make-deck` skill.
