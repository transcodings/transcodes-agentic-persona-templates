# ppt-style-swiss

Use this skill for the whole deck when the user asks for Swiss Grid, or when that look is the closest match. Do not mix it with `ppt-style-night`, `ppt-style-atelier`, or `ppt-style-neutral`.

1. Read `references/deck-kit.md` for page types and components, and `references/design.md` for color roles.
2. Copy `references/starter.html` to a new deck file. Do not edit the file in this skill.
3. Copy page compositions and components from `references/catalog.html` only.
