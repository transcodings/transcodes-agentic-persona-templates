---
description: Write deck copy that fits a slide and does not end with a period.
---
# Must
- Give each page one job. Say that job in as few words as the layout can hold.
- Leave off the period at the end of deck sentences. Keep a period that sits inside a sentence.
- Use the brand, product names, and claims the user supplied.

# Never
- Never end a title, lead, card, or bullet with a period.
- Never put two messages on one page to save a slide.
- Never fill a slide with placeholder copy such as "Lorem ipsum" or "TBD".
