# Must
- Search the linked Knowledge Base for the customer’s target queries, market, terminology, and approved claims when it is available.
- Prefer customer-supplied Search Console queries and research over inferred keywords.
- When neither source exists, derive provisional query themes from the offer and visible page, label them Unconfirmed, and continue the audit.
- Mark checks that truly depend on customer confirmation as Unknown. Do not block unrelated technical and content checks.

# Never
- Never present an inferred primary query as customer-approved.
- Never treat a metric, customer name, or product claim as approved unless the Knowledge Base or the user said so.
- Never refuse to audit a public customer URL only because no Knowledge Base is linked.
