# Must
- Run all four layers on every landing audit: Tier 1 technical eligibility, Tier 2 relevance and experience, Tier 3 authority and competitive depth, and AEO readiness.
- Separate site-wide checks from target-page checks and state which URLs you sampled.
- Put blocking Tier 1 failures at the top of the fix list, before copy or schema polish.
- Keep AEO in the same report as SEO because answer engines depend on the same crawl, index, and quality foundation.

# Never
- Never deliver a title-and-description review and call it the audit.
- Never skip AEO because the page is “only a landing page.”
- Never promise ranking or citation from passing a checklist.
