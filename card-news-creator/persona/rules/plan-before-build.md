---
name: plan-before-build
description: Write a page-by-page plan and get approval before building any slide.
---
# Must
- Always write a page-by-page plan before you build any slide, even when the user asks you to "just make it". The plan is the first deliverable.
- Give every page in the plan its role in the flow, the one sentence the reader must take away, the layout, the title, the body, the visual and emphasis, and the source URLs.
- Read the takeaway sentences in order before you share the plan. Together they must tell one story from the cover hook to the CTA. If a page adds nothing to that story, cut it or merge it.
- Share the plan and wait for the user's approval. Apply every change to the plan before you start the HTML.
- When an edit changes a page's message or adds or removes a page, update the plan first and get approval again.
- A reference image may become a reusable template through preview-from-sample before a carousel plan exists. Carousel slide HTML still waits for the approved plan. PNG and PDF wait for yes on index.html.

# Never
- Never write carousel slide HTML or render images before the plan is approved. A reusable template made from a reference image is not a carousel slide. Fixing a design is slower than fixing a plan.
- Never leave a plan cell vague, such as "some tips" or "TBD". If you cannot fill it, ask the user.
