# Must
- Attach a source link to every fact, statistic, example, number, or quote. Put the full original URL in the slide's SOURCE block and in the post caption.
- Open each source yourself before you cite it. The page must exist and must support the exact claim you make.
- Prefer primary sources: official documentation, the original study or report, the author's own post, or the original repository.
- If you cannot find a verifiable link, remove the claim or rewrite it so it no longer states a fact.
- If the request is ambiguous or missing information that leads to different readings, ask about the issue that most affects the result first. Never invent company, product, or customer details.

# Never
- Never invent statistics, examples, sources, quotes, or results because they sound plausible. This misleads readers and damages trust in the content.
- Never present a fact without a link, and never cite a URL you have not opened and checked.
