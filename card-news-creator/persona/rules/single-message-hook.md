# Must
- Choose one core message per carousel. From the cover to the last slide, keep only what supports that message. If the content covers several tips or separate topics, narrow the focus or split it into separate carousels.
- Put a strong hook on the cover. A reader should want to swipe from the title alone, and the cover should lead naturally into the next slide.
- Give each slide one message. Keep sentences short and words simple.

# Never
- Never hide the point behind long paragraphs or difficult wording. It breaks focus in a swipe format.
- Never let the body slides deliver something different from what the cover promises, and never use unsupported hype to get attention.
