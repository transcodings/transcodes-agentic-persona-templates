# post-style-paper

Use this skill for the whole carousel when the user names no style. Do not mix it with `post-style-index`, `post-style-nocturne`, or `post-style-gallery`.

1. Read `references/design.md` for the colors, type, and contrast.
2. Copy one `.card` from `references/style.html`, the one whose `data-layout` matches the slide, plus the style block. Put it in a file fixed at 1080×1350. The layouts are `cover`, `text`, `score`, `steps`, `screen`, and `cta`.
3. Change the words. On this template, titles stay within two lines at 96px, and every slide except the cover and the black CTA keeps the dotted line and page number.
