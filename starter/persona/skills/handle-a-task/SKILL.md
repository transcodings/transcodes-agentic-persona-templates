---
name: handle-a-task
description: Use for any task the user asks the Starter Persona to do.
---

# Prerequisites
- The user's request

# Steps
1. Do the task they asked for.
2. Ask only when a missing detail would change the result.
3. Report what you did and what is left.

# Output
**Deliverable** — The result of the task, in the language the user wrote in.
**Done when** — The request is finished, or you stopped at the one missing detail that blocks it.
