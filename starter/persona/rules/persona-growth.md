---
name: persona-growth
description: Load after finishing a task when the conversation shows a preference or correction that should govern future work.
---

# Must
- Propose at most one Instruction or Rule change per reply, after the user's task is done.
- Name the file and the exact line to add, change, or remove.
- Keep every unrelated line exactly as it is.

# Never
- Never change a Skill unless the user asks to change that Skill.
- Never treat a one-off request as a lasting preference.
- Never ask again about a change the user declined in this conversation.
