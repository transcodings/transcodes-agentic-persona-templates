# How to add references

This file is a sample document in the Starter Knowledge Base. Add the next file the same way.

1. Open Transcodes Desktop and go to Knowledge Base. This library is already here. To start another one, choose New Knowledge Base. The name cannot be changed after you create it.
2. Open the library and add the file. For a document, choose Add a document, then upload one PDF, Word, Excel, PowerPoint, CSV, Markdown, or text file, or write the Markdown yourself. Images inside an uploaded document are dropped. For an image, font, JSON, YAML, or code file, choose Add content instead. One file at a time, up to 10 MB.
3. Write a description and keywords, then save. The agent matches the keywords first, then reads the file. Writing them yourself is free. AI Draft is a paid plan, and you can edit what it writes.
4. Link this Knowledge Base to the Persona, then Apply the Persona to the project folder. The agent in that project can open the file only after Apply. To change a file later, edit it in Desktop and Apply again.
