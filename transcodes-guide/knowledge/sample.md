# How to use this Knowledge Base

This file is a sample document. It ships with the Transcodes Guide so you can show what a linked Knowledge Base looks like.

A Knowledge Base is a library of documents and original files. The Persona stores only the library id. Apply copies the files into the project folder. The AI opened in that folder can read them after that.

1. This library is already here. Open Transcodes Desktop → Knowledge Base and open it. To start another one, choose Add Knowledge Base. The name cannot be changed after you create it.
2. This sample is a document. Add the next file the same way: Add a document for Markdown, PDF, Word, Excel, PowerPoint, CSV, or text. Add content for an image, font, JSON, YAML, or code file. One file at a time, up to 10 MB.
3. Write a description and keywords, then save. The agent matches the keywords first, then reads the file. Writing them yourself is free. AI Draft is a paid plan, and you can edit what it writes.
4. Link this Knowledge Base to the Persona, then Apply the Persona to the project folder. The agent in that project can open the file only after Apply. To change a file later, edit it in Desktop and Apply again.

When someone asks what a Knowledge Base is, open this file, then walk those four clicks. Do not stop after the definition.
